## ✨ Funcionalidades

| Categoria | O que faz |
|---|---|
| 🧹 **Limpeza de ficheiros** | Remove temporários, cache de browsers e esvazia a Reciclagem |

| 🧠 **Memória & CPU** | Mostra uso em tempo real e liberta RAM |
| ⚙️ **Serviços em segundo plano** | Verifica e para serviços que consomem recursos |
| 💾 **Disco & arranque** | Relatório de espaço e lista de programas de arranque |
| 🚀 **Otimização completa** | Corre todas as limpezas seguras numa só opção |

**12 ferramentas no total**, tudo num único script, sem instalação complicada.

## 🚀 Instalação

### 1. Clona ou descarrega este repositório

```bash
git clone https://github.com/teu-user/mega-otimizador.git
cd mega-otimizador
```

Ou simplesmente descarrega o `mega_otimizador.py` diretamente desta página.

### 2. Instala o Python (se ainda não tiveres)

Vai a [python.org/downloads](https://www.python.org/downloads/) e descarrega a versão mais recente.

Durante a instalação, marca a opção **"Add python.exe to PATH"** antes de clicares em "Install Now" — isto é essencial para o comando `python` funcionar no terminal.

Depois, confirma que ficou instalado abrindo o terminal (cmd ou PowerShell) e correndo:

```bash
python --version
```

### 3. Instala as dependências

```bash
pip install colorama psutil
```

### 4. Corre o script

```bash
python mega_otimizador.py
```

> 💡 **Dica:** corre o terminal como **Administrador** para teres acesso a todas as funcionalidades (serviços, registo, etc.).
